Subject residuals

sleepstudy has the average reaction time, in milliseconds, of 18 subjects on each of 10 days of sleep deprivation (Belenky et al., 2003).

  • PHP 8.5+
  • PHP 8.3–8.4
// Fit one line for all subjects, then average each
// subject's residuals.
$sleep = DataFrame::fromCsv("$data/sleepstudy.csv");
$fit = $sleep |> lm('Reaction ~ Days');
[$b0, $bDays] = $fit['coefficients'];

$expected = fn ($r) => $b0 + $bDays * $r->Days;
$shareAbove = fn ($g) => round(\count(array_filter(
    $g->column('residual'),
    fn ($e) => $e > 0,
)) / $g->nrow(), 2);

echo $sleep |>
    mutate(
        residual: fn ($r) => $r->Reaction - $expected($r),
    ) |>
    group_by('Subject') |>
    summarize(
        days: n(),
        avg_reaction: mean('Reaction'),
        avg_residual: mean('residual'),
        share_above: $shareAbove,
    ) |>
    mutate(
        rank: min_rank(desc('avg_residual')),
        avg_reaction: fn ($r) => round($r->avg_reaction, 1),
        avg_residual: fn ($r) => round($r->avg_residual, 1),
    ) |>
    arrange('rank') |>
    head(5);

Subjects as random intercepts

  • PHP 8.5+
  • PHP 8.3–8.4
// Days nested in subjects: a shared intercept and slope,
// and one intercept shift per subject.
$sleep = DataFrame::fromCsv("$data/sleepstudy.csv");
$formula = 'Reaction ~ Days + (1 | Subject)';
$fit = $sleep |> lmer($formula);

foreach ($fit['columns'] as $i => $term) {
    printf(
        "%-12s %8.4f  (se %.4f)\n",
        $term,
        $fit['coefficients'][$i],
        $fit['std_errors'][$i],
    );
}
$subjectSd = $fit['theta'][0] * $fit['sigma'];
$icc = $subjectSd ** 2
    / ($subjectSd ** 2 + $fit['sigma'] ** 2);
printf(
    "subject sd %.3f, residual sd %.3f, ICC %.3f\n\n",
    $subjectSd,
    $fit['sigma'],
    $icc,
);

// Each subject's raw mean reaction time beside its
// estimated intercept shift.
$random = $fit['random'][0];
$shifts = array_combine(
    $random['group_labels'],
    array_column($random['effects'], 0),
);
echo $sleep |>
    group_by('Subject') |>
    summarize(days: n(), raw_mean: mean('Reaction')) |>
    mutate(
        intercept_shift: fn ($r) =>
            round($shifts[$r->Subject], 1),
        raw_mean: fn ($r) => round($r->raw_mean, 1),
    ) |>
    arrange(desc('intercept_shift')) |>
    head(5);

Fuel economy by cylinders

mtcars has fuel consumption and design measurements for 32 cars from the 1974 Motor Trend magazine. mpg is miles per US gallon, hp is gross horsepower, and wt is weight in 1,000 lb.

  • PHP 8.5+
  • PHP 8.3–8.4
// Fuel economy, power, and weight by number of cylinders,
// and each car's mpg against its cylinder group's mean.
$cars = DataFrame::fromCsv("$data/mtcars.csv") |>
    rename(model: 'rownames');

echo $cars |>
    group_by('cyl') |>
    summarize(
        across(
            ['mpg', 'hp', 'wt'],
            ['mean' => mean(...), 'max' => max(...)],
        ),
        cars: n(),
    ) |>
    mutate(across(
        where('double'),
        fn ($v) => round($v, 1),
    ));

$vsGroup = fn ($r, $g) => round(
    $r->mpg - mean('mpg')($g),
    1,
);
echo "\n\n", $cars |>
    select('model', 'cyl', 'mpg') |>
    mutate(vs_group: $vsGroup, _by: 'cyl') |>
    arrange('cyl', desc('vs_group'));

Labor-force participation by age

mroz has 753 married women in 1975 from the Panel Study of Income Dynamics: whether each was in the labor force (lfp), her age, her number of children under 6 (k5) and from 6 to 18 (k618), and family income excluding her earnings (inc, in $1,000s).

  • PHP 8.5+
  • PHP 8.3–8.4
// Labor-force participation by age quartile, then a
// logistic regression.
$mroz = DataFrame::fromCsv("$data/mroz.csv") |>
    mutate(in_lf: if_else(col('lfp')->eq('yes'), 1, 0));

echo $mroz |>
    mutate(age_quartile: ntile('age', 4)) |>
    group_by('age_quartile') |>
    summarize(
        women: n(),
        min_age: min('age'),
        max_age: max('age'),
        participation: mean('in_lf'),
    );

$fit = $mroz |> glm(
    'in_lf ~ age + k5 + k618 + inc',
    family: 'binomial',
);
echo "\n\nOdds ratios\n";
$terms = array_slice($fit['columns'], 1, null, true);
foreach ($terms as $i => $term) {
    $ratio = exp($fit['coefficients'][$i]);
    printf("%-5s %.3f\n", $term, $ratio);
}

Warp breaks by wool and tension

warpbreaks has the number of warp breaks per loom for 54 looms, by wool type (A or B) and tension (low, medium, or high).

  • PHP 8.5+
  • PHP 8.3–8.4
// Mean breaks by wool and tension, as a cross-tabulation,
// then a Poisson regression.
$looms = DataFrame::fromCsv("$data/warpbreaks.csv")
    ->asFactor('tension', ['L', 'M', 'H']);

echo $looms |>
    group_by('wool', 'tension') |>
    summarize(
        mean_breaks: mean('breaks'),
        _groups: 'drop',
    ) |>
    mutate(
        mean_breaks: fn ($r) => round($r->mean_breaks, 1),
    ) |>
    pivot_wider(
        namesFrom: 'tension',
        valuesFrom: 'mean_breaks',
    );

$fit = $looms |> glm(
    'breaks ~ wool + tension',
    family: 'poisson',
);
echo "\n\nRate ratios\n";
$terms = array_slice($fit['columns'], 1, null, true);
foreach ($terms as $i => $term) {
    $ratio = exp($fit['coefficients'][$i]);
    printf("%-8s %.3f\n", $term, $ratio);
}
