Functions and methods

phplyr’s functions are namespaced functions in Phplyr. A function marked with a chain method also runs as that method on phplyr($table). Expression methods are called on the vector helpers that col() and other functions return.

Pipes and method chains

Function Chain method Purpose
phplyr() Start a method chain on a table.
pipe() Apply steps to a value in order.

Single-table functions

Rows

Function Chain method Purpose
filter() ->filter() Keep rows where every condition is true.
filter_out() ->filterOut() Drop rows where every condition is true (dplyr 1.2).
arrange() ->arrange() Sort rows by columns or expressions.
desc() Descending sort key for arrange(), and for rank helpers.
distinct() ->distinct() Unique rows over the given columns (all columns when none are given).
slice() ->slice() Rows by 1-based position within each group, like dplyr’s slice().
slice_head() ->sliceHead() First rows of each group.
slice_tail() ->sliceTail() Last rows of each group.
slice_min() ->sliceMin() Rows with the smallest values of $orderBy in each group, ordered by it.
slice_max() ->sliceMax() Rows with the largest values of $orderBy in each group, ordered by it.
slice_sample() ->sliceSample() Random rows from each group.
head() ->head() First $n rows of the whole table, ignoring groups (like utils::head).
top_n() ->topN() The n rows with the largest wt in each group, ties included, in their original order (superseded by slice_max()).
top_frac() ->topFrac() top_n() with a proportion of each group’s rows (superseded by slice_max(prop:)).
sample_n() ->sampleN() n random rows from each group (superseded by slice_sample()).
sample_frac() ->sampleFrac() A proportion of random rows from each group (superseded by slice_sample(prop:)).
add_row() ->addRow() Add rows of values.

Columns

relocate() ->relocate() Move columns.
mutate() ->mutate() Add, replace, or drop (with null) columns, named by argument.
transmute() ->transmute() Like mutate(), keeping only the grouping columns and the new columns.

Function Chain method Purpose

summarize() ->summarize() Alias of summarise().
reframe() ->reframe() Like summarise(), but each summary may return any number of values (a list).
count() ->count() Count rows per combination of columns, within any existing groups.
tally() ->tally() Count rows in each group (summarise(n = n())).
add_count() ->addCount() Like count(), but adds the count as a column instead of summarising.
add_tally() ->addTally() Like tally(), but adds the count as a column.
glimpse() ->glimpse() Print a compact column-by-column summary and return the table unchanged, so it can sit in the middle of a pipeline.

Chain methods

phplyr($table) starts a chain. Each function above with a chain method runs as that method. These methods belong to the chain itself:

Method Purpose
->get() Return the table.
->pipe() Apply your own functions to the table and continue the chain with the result.
