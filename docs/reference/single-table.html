Single-table functions

Rows

filter() keeps rows where every condition is true. Conditions are row closures, vector helpers such as between() or if_any(), or the name of a logical column. NA counts as false. filter_out() drops the rows where every condition is true and keeps rows where a condition is NA, so filter() and filter_out() with the same conditions split a table without overlap.

  • PHP 8.5+
  • PHP 8.3–8.4
$schools = DataFrame::fromCsv('schools.csv');

// Several conditions are combined with AND; NA counts as false.
echo $schools |>
    filter(fn ($r) => $r->prior_score > 75, between('study_hours', 2, 6)) |>
    head(4);

// filter_out() drops the rows where every condition is true.
echo "\n", $schools |> filter_out(fn ($r) => $r->prior_score < 70) |> count();
$schools = DataFrame::fromCsv('schools.csv');

// Several conditions are combined with AND; NA counts as false.
echo phplyr($schools)
    ->filter(fn ($r) => $r->prior_score > 75, between('study_hours', 2, 6))
    ->head(4);

// filter_out() drops the rows where every condition is true.
echo "\n", phplyr($schools)->filterOut(fn ($r) => $r->prior_score < 70)->count();
# A tibble: 0 × 4
# ℹ 4 variables: school <chr>, study_hours <dbl>, prior_score <dbl>,
#   score <dbl>
# A tibble: 1 × 1
      n
  <int>
1    59

In a grouped table, the second closure argument is the row’s group, and vector helpers are evaluated per group:

  • PHP 8.5+
  • PHP 8.3–8.4
// Inside a group, the second closure argument is the group's table, and
// vector helpers such as max() are evaluated per group.
echo DataFrame::fromCsv('schools.csv') |>
    group_by('school') |>
    filter(fn ($r, $g) => $r->score === max('score')($g)) |>
    select('school', 'score') |>
    head(4);
// Inside a group, the second closure argument is the group's table, and
// vector helpers such as max() are evaluated per group.
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->groupBy('school')
    ->filter(fn ($r, $g) => $r->score === max('score')($g))
    ->select('school', 'score')
    ->head(4);
# A tibble: 4 × 2
# Groups:   school [4]
  school    score
  <chr>     <dbl>
1 school-01  91.0
2 school-02  92.1
3 school-03  84.0
4 school-04  83.9

arrange() sorts rows. It is stable and puts NA last. Keys are column names, desc(), or expressions, which are evaluated over the whole table. It ignores grouping unless you pass _byGroup: true.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromCsv('housing.csv') |>
    arrange('bedrooms', desc(fn ($r) => $r->monthly_rent / $r->area_m2));
echo phplyr(DataFrame::fromCsv('housing.csv'))
    ->arrange('bedrooms', desc(fn ($r) => $r->monthly_rent / $r->area_m2));

distinct() keeps unique rows over the given columns, or over all columns. Named arguments add computed columns first, and _keepAll: true keeps every column from the first row of each combination.

The slice family picks rows within each group:

Function Rows
slice(1, 3), slice(-1) By 1-based position; negative positions drop rows.
slice_head(n:), slice_tail(n:) The first or last rows.
slice_min(x, n:), slice_max(x, n:) The rows with the smallest or largest values, with ties kept unless withTies: false.
slice_sample(n:, replace:, weightBy:) Random rows. Seed with mt_srand().
head(n) The first rows of the whole table, ignoring groups.
top_n(n, wt), top_frac(prop, wt) Superseded by slice_max(). Rows ranked within n, in table order.
sample_n(size), sample_frac(size) Superseded by slice_sample().
add_row(x: 1, _before:, _after:) New rows of values; columns not given are NA.

Each takes prop: in place of n:, and _by:.

  • PHP 8.5+
  • PHP 8.3–8.4
$schools = DataFrame::fromCsv('schools.csv') |> group_by('school');

// The two best students in each of the first three schools.
echo $schools |>
    slice_max('score', n: 2) |>
    filter(fn ($r) => $r->school <= 'school-03') |>
    select('school', 'score');
$schools = phplyr(DataFrame::fromCsv('schools.csv'))->groupBy('school')->get();

// The two best students in each of the first three schools.
echo phplyr($schools)
    ->sliceMax('score', n: 2)
    ->filter(fn ($r) => $r->school <= 'school-03')
    ->select('school', 'score');

filter()

filter(mixed ...$conditions): Closure

Keep rows where every condition is true; NA counts as false. Conditions are row closures fn ($r, $group), vector helpers such as between('x', 1, 5) or if_any(...), or a logical column name. Option: _by.

Returns a function of a table, which returns a table. Chain method: ->filter(). An unknown underscored option throws InvalidArgumentException. Example.

filter_out()

filter_out(mixed ...$conditions): Closure

Drop rows where every condition is true (dplyr 1.2). NA counts as false, so rows with NA conditions are kept: filter() and filter_out() together see every row exactly once. Option: _by.

Returns a function of a table, which returns a table. Chain method: ->filterOut(). An unknown underscored option throws InvalidArgumentException. Example.

arrange()

arrange(mixed ...$keys): Closure

Sort rows by columns or expressions; desc() reverses. Stable; NA last. Ignores grouping unless _byGroup: true.

Returns a function of a table, which returns a table. Chain method: ->arrange(). An unknown underscored option throws InvalidArgumentException. Example.

desc()

desc(mixed $x): Desc

Descending sort key for arrange(), and for rank helpers: min_rank(desc('x')).

Returns Desc. Example.

distinct()

distinct(mixed ...$columns): Closure

Unique rows over the given columns (all columns when none are given). Named arguments add computed columns first. Option: _keepAll (keep every column, from the first row of each combination).

Returns a function of a table, which returns a table. Chain method: ->distinct(). An unknown underscored option throws InvalidArgumentException. Example.

slice()

slice(array|int ...$positions): Closure

Rows by 1-based position within each group, like dplyr’s slice(): slice(1, 2), slice(range(1, 5)), or negative positions to drop rows. Option: _by.

Returns a function of a table, which returns a table. Chain method: ->slice(). An unknown underscored option throws InvalidArgumentException.

slice_head()

slice_head(?int $n = null, ?float $prop = null, mixed $_by = null): Closure

First rows of each group: slice_head(n: 3) or slice_head(prop: 0.1).

Returns a function of a table, which returns a table. Chain method: ->sliceHead().

slice_tail()

slice_tail(?int $n = null, ?float $prop = null, mixed $_by = null): Closure

Last rows of each group.

Returns a function of a table, which returns a table. Chain method: ->sliceTail().

slice_min()

slice_min(mixed $orderBy, ?int $n = null, ?float $prop = null, bool $withTies = true, bool $naRm = false, mixed $_by = null): Closure

Rows with the smallest values of $orderBy in each group, ordered by it.

Returns a function of a table, which returns a table. Chain method: ->sliceMin().

slice_max()

slice_max(mixed $orderBy, ?int $n = null, ?float $prop = null, bool $withTies = true, bool $naRm = false, mixed $_by = null): Closure

Rows with the largest values of $orderBy in each group, ordered by it.

Returns a function of a table, which returns a table. Chain method: ->sliceMax(). Example.

slice_sample()

slice_sample(?int $n = null, ?float $prop = null, bool $replace = false, mixed $weightBy = null, mixed $_by = null): Closure

Random rows from each group. Uses mt_rand(), so mt_srand() makes it reproducible. $weightBy is a column of non-negative weights.

Returns a function of a table, which returns a table. Chain method: ->sliceSample().

head()

head(int $n = 6): Closure

First $n rows of the whole table, ignoring groups (like utils::head).

Returns a function of a table, which returns a table. Chain method: ->head(). Example.

top_n()

top_n(int $n, mixed $wt = null): Closure

The n rows with the largest wt in each group, ties included, in their original order (superseded by slice_max()). A negative n takes the smallest. Without wt, the last column.

Returns a function of a table, which returns a table. Chain method: ->topN().

top_frac()

top_frac(float $n, mixed $wt = null): Closure

top_n() with a proportion of each group’s rows (superseded by slice_max(prop:)).

Returns a function of a table, which returns a table. Chain method: ->topFrac().

sample_n()

sample_n(int $size, bool $replace = false, mixed $weight = null): Closure

n random rows from each group (superseded by slice_sample()).

Returns a function of a table, which returns a table. Chain method: ->sampleN().

sample_frac()

sample_frac(float $size = 1.0, bool $replace = false, mixed $weight = null): Closure

A proportion of random rows from each group (superseded by slice_sample(prop:)).

Returns a function of a table, which returns a table. Chain method: ->sampleFrac().

add_row()

add_row(mixed ...$values): Closure

Add rows of values: add_row(x: 4, y: 'd'), or several with lists: add_row(x: [4, 5]). Columns not given are NA. Options: _before, _after (a 1-based row; the default adds at the end).

Returns a function of a table, which returns a table. Chain method: ->addRow(). Throws InvalidArgumentException on invalid arguments. An unknown underscored option throws InvalidArgumentException.

Columns

select() keeps columns by name or with tidyselect helpers. An associative array renames while selecting. rename() renames with new: 'old' arguments, rename_with() applies a function to selected names, and relocate() moves columns to the front or _before / _after another column.

  • PHP 8.5+
  • PHP 8.3–8.4
$schools = DataFrame::fromCsv('schools.csv');

echo implode(', ', ($schools |> select('school', ends_with('score')))->columns()), "\n";
echo implode(', ', ($schools |> select(except('school')))->columns()), "\n";
echo implode(', ', ($schools |> select(where('numeric')))->columns()), "\n";
echo implode(', ', ($schools |> select(['hours' => 'study_hours'], everything()))->columns()), "\n";
echo implode(', ', ($schools |> relocate('score', _before: 'study_hours'))->columns()), "\n";
echo implode(', ', ($schools |> rename_with(strtoupper(...), contains('score')))->columns()), "\n";
$schools = DataFrame::fromCsv('schools.csv');

echo implode(', ', (phplyr($schools)->select('school', ends_with('score'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(except('school'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(where('numeric'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(['hours' => 'study_hours'], everything())->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->relocate('score', _before: 'study_hours')->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->renameWith(strtoupper(...), contains('score'))->get())->columns()), "\n";

mutate() adds or replaces columns. A value can be a row closure, a vector helper, a list with one value per row, a scalar, or null to drop the column. Later arguments see the columns made by earlier ones.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromCsv('housing.csv') |>
    mutate(
        rent_per_m2: fn ($r) => round($r->monthly_rent / $r->area_m2, 2),
        size: if_else(fn ($r) => $r->area_m2 >= 60, 'large', 'small'),
        rank: min_rank(desc('monthly_rent')),
    ) |>
    arrange('rank');
echo phplyr(DataFrame::fromCsv('housing.csv'))
    ->mutate(
        rent_per_m2: fn ($r) => round($r->monthly_rent / $r->area_m2, 2),
        size: if_else(fn ($r) => $r->area_m2 >= 60, 'large', 'small'),
        rank: min_rank(desc('monthly_rent')),
    )
    ->arrange('rank');

mutate() takes dplyr’s options: _by groups for one call, _keep: 'none' keeps only the grouping and new columns, and _before or _after place the new columns. transmute() is mutate() that keeps only the new columns.

  • PHP 8.5+
  • PHP 8.3–8.4
$housing = DataFrame::fromCsv('housing.csv');

// _keep: 'none' keeps only new columns (and grouping columns).
echo $housing |> mutate(rent_k: fn ($r) => $r->monthly_rent / 1000, _keep: 'none') |> head(3);

// _by groups for this call only; mean() is recycled within each group.
echo "\n", $housing |>
    mutate(vs_bedroom_avg: fn ($r, $g) => $r->monthly_rent - mean('monthly_rent')($g), _by: 'bedrooms', _after: 'bedrooms') |>
    head(4);
$housing = DataFrame::fromCsv('housing.csv');

pull() returns one column as a PHP list. It takes a name or a position (1-based, negative from the end, the last column by default) and an optional name: column whose values become the keys.

  • PHP 8.5+
  • PHP 8.3–8.4
$housing = DataFrame::fromCsv('housing.csv');

echo $housing |> distinct('bedrooms') |> arrange('bedrooms');
echo "\n", json_encode($housing |> arrange('area_m2') |> pull('monthly_rent')), "\n";
echo json_encode($housing |> pull(-1)), "\n";
$housing = DataFrame::fromCsv('housing.csv');

echo phplyr($housing)->distinct('bedrooms')->arrange('bedrooms');
echo "\n", json_encode(phplyr($housing)->arrange('area_m2')->pull('monthly_rent')), "\n";
echo json_encode(phplyr($housing)->pull(-1)), "\n";

select()

select(mixed ...$columns): Closure

Keep or drop columns: names, lists of names, selectors such as starts_with('x') or except('id'). Named arguments rename: select(id: 'ID').

Returns a function of a table, which returns a table. Chain method: ->select(). Example.

rename()

rename(string ...$map): Closure

Rename columns, new name as the argument name: rename(price: 'cost').

Returns a function of a table, which returns a table. Chain method: ->rename().

rename_with()

rename_with(Closure $fn, mixed $cols = null): Closure

Rename selected columns (all by default) with a function of the old name.

Returns a function of a table, which returns a table. Chain method: ->renameWith(). Example.

relocate()

relocate(mixed ...$columns): Closure

Move columns: to the front by default, or _before / _after a column. Named arguments rename while moving.

Returns a function of a table, which returns a table. Chain method: ->relocate(). An unknown underscored option throws InvalidArgumentException. Example.

mutate()

mutate(mixed ...$columns): Closure

Add, replace, or drop (with null) columns, named by argument: mutate(log_price: fn ($r) => log($r->price), rank: min_rank('price')).

Values may be a row closure fn ($r, $group), a vector helper (lag, cumsum, mean…; summaries recycle within groups), a list with one value per row, a scalar, or null to drop the column. across(...) may be passed first.

Options: _by, _keep (‘all’, ‘none’), _before, _after.

Returns a function of a table, which returns a table. Chain method: ->mutate(). An unknown underscored option throws InvalidArgumentException. Example.

transmute()

transmute(mixed ...$columns): Closure

Like mutate(), keeping only the grouping columns and the new columns. A bare column name keeps that column: transmute('id', half: ...).

Returns a function of a table, which returns a table. Chain method: ->transmute(). An unknown underscored option throws InvalidArgumentException.

pull()

pull(string|int $var = -1, ?string $name = null): Closure

Extract one column as a PHP list: by name, or by position like dplyr (1 is the first column, -1 the last; the default). With $name, the list is keyed by that column’s values.

Returns a function of a table, which returns a PHP list of the column’s values. Chain method: ->pull(). Throws OutOfRangeException on invalid arguments. Example.

Summaries

summarize() returns one row per group. summarise() is the same function. Each named argument is a summary helper or a closure that receives the group’s table and returns one value. With several grouping columns, the result drops the last one, as in dplyr. _groups accepts 'drop_last', 'drop', 'keep', and 'rowwise'.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromCsv('schools.csv') |>
    summarize(
        students: n(),
        schools: n_distinct('school'),
        median_hours: median('study_hours'),
        q90_score: quantile('score', 0.9),
        iqr_score: iqr('score'),
        top_school: fn ($g) => ($g |> slice_max('score', n: 1) |> pull('school'))[0],
    );
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->summarize(
        students: n(),
        schools: n_distinct('school'),
        median_hours: median('study_hours'),
        q90_score: quantile('score', 0.9),
        iqr_score: iqr('score'),
        top_school: fn ($g) => (phplyr($g)->sliceMax('score', n: 1)->pull('school'))[0],
    );
# A tibble: 1 × 6
  students schools median_hours q90_score iqr_score top_school
     <int>   <int>        <dbl>     <dbl>     <dbl> <chr>     
1      250      12         6.66      86.1      15.3 school-06

reframe() is summarize() for summaries that return several values. Results are recycled to a common length within each group, and the output is ungrouped.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromCsv('schools.csv') |>
    filter(fn ($r) => $r->school <= 'school-02') |>
    group_by('school') |>
    reframe(
        p: [0.25, 0.5, 0.75],
        score: fn ($g) => array_map(fn ($p) => Stats::quantile($g->column('score'), $p), [0.25, 0.5, 0.75]),
    );
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->filter(fn ($r) => $r->school <= 'school-02')
    ->groupBy('school')
    ->reframe(
        p: [0.25, 0.5, 0.75],
        score: fn ($g) => array_map(fn ($p) => Stats::quantile($g->column('score'), $p), [0.25, 0.5, 0.75]),
    );
# A tibble: 6 × 3

count() counts rows per combination of columns within any existing groups and keeps the original grouping. wt: sums a column instead, sort: true orders by the count, and name: names the count column. tally() counts within the current groups, and add_count() and add_tally() add the count as a column.

  • PHP 8.5+
  • PHP 8.3–8.4
$schools = DataFrame::fromCsv('schools.csv') |>
    mutate(band: case_when(
        [fn ($r) => $r->study_hours < 4, 'light'],
        [fn ($r) => $r->study_hours < 8, 'moderate'],
        default: 'heavy',
    ));

echo $schools |> count('band', sort: true);
echo "\n", $schools |> count('band', wt: 'study_hours', name: 'hours');
$schools = phplyr(DataFrame::fromCsv('schools.csv'))
    ->mutate(band: case_when(
        [fn ($r) => $r->study_hours < 4, 'light'],
        [fn ($r) => $r->study_hours < 8, 'moderate'],
        default: 'heavy',
    ))
    ->get();

echo phplyr($schools)->count('band', sort: true);
echo "\n", phplyr($schools)->count('band', wt: 'study_hours', name: 'hours');

Returns a function of a table, which returns a table. Chain method: ->summarise(). An unknown underscored option throws InvalidArgumentException.

summarize()

Alias of summarise().

Returns a function of a table, which returns a table. Chain method: ->summarize(). Example.

Like summarise(), but each summary may return any number of values (a list); they are recycled to a common length per group. The result is ungrouped. Option: _by.

Returns a function of a table, which returns a table. Chain method: ->reframe(). An unknown underscored option throws InvalidArgumentException. Example.

Count rows per combination of columns, within any existing groups. The result keeps the original grouping, like dplyr. Options: wt (column to sum instead of counting), sort, name.

Returns a function of a table, which returns a table. Chain method: ->count(). Example.

Returns a function of a table, which returns a table. Chain method: ->tally().

Like count(), but adds the count as a column instead of summarising.
