Single-table functions

Rows

filter() keeps rows where every condition is true. Conditions are row closures, vector helpers such as between() or if_any(), or the name of a logical column. NA counts as false. filter_out() drops the rows where every condition is true and keeps rows where a condition is NA, so filter() and filter_out() with the same conditions split a table without overlap.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = DataFrame::fromCsv('schools.csv');

// Several conditions are combined with AND; NA counts as false.
echo phplyr($schools)
    ->filter(fn ($r) => $r->prior_score > 75, between('study_hours', 2, 6))
    ->head(4);

// filter_out() drops the rows where every condition is true.
echo "\n", phplyr($schools)->filterOut(fn ($r) => $r->prior_score < 70)->count();
$schools = DataFrame::fromCsv('schools.csv');

// Several conditions are combined with AND; NA counts as false.
echo $schools
    |> filter(fn ($r) => $r->prior_score > 75, between('study_hours', 2, 6))
    |> head(4);

// filter_out() drops the rows where every condition is true.
echo "\n", $schools |> filter_out(fn ($r) => $r->prior_score < 70) |> count();
# A tibble: 0 × 4
# ℹ 4 variables: school <chr>, study_hours <dbl>, prior_score <dbl>,
#   score <dbl>
# A tibble: 1 × 1
      n
  <int>
1    59

In a grouped table, the second closure argument is the row’s group, and vector helpers are evaluated per group:

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
// Inside a group, the second closure argument is the group's table, and
// vector helpers such as max() are evaluated per group.
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->groupBy('school')
    ->filter(fn ($r, $g) => $r->score === max('score')($g))
    ->select('school', 'score')
    ->head(4);
// Inside a group, the second closure argument is the group's table, and
// vector helpers such as max() are evaluated per group.
echo DataFrame::fromCsv('schools.csv')
    |> group_by('school')
    |> filter(fn ($r, $g) => $r->score === max('score')($g))
    |> select('school', 'score')
    |> head(4);
# A tibble: 4 × 2
# Groups:   school [4]

  <chr>     <dbl>

2 school-02  92.1
3 school-03  84.0

arrange() sorts rows. It is stable and puts NA last. Keys are column names, desc(), or expressions, which are evaluated over the whole table. It ignores grouping unless you pass byGroup: true.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
echo phplyr(DataFrame::fromCsv('housing.csv'))
    ->arrange('bedrooms', desc(fn ($r) => $r->monthly_rent / $r->area_m2));
echo DataFrame::fromCsv('housing.csv')
    |> arrange('bedrooms', desc(fn ($r) => $r->monthly_rent / $r->area_m2));

distinct() keeps unique rows over the given columns, or over all columns. Named arguments add computed columns first, and keepAll: true keeps every column from the first row of each combination.

The slice family picks rows within each group:

Function Rows
slice(1, 3), slice(-1) By 1-based position; negative positions drop rows.
slice_head(n:), slice_tail(n:) The first or last rows.
slice_min(x, n:), slice_max(x, n:) The rows with the smallest or largest values, with ties kept unless withTies: false.
slice_sample(n:, replace:, weightBy:) Random rows. Seed with mt_srand().
head(n) The first rows of the whole table, ignoring groups.
top_n(n, wt), top_frac(prop, wt) Superseded by slice_max(). Rows ranked within n, in table order.
sample_n(size), sample_frac(size) Superseded by slice_sample().
add_row(x: 1, before:, after:) New rows of values; columns not given are NA.

Each takes prop: in place of n:, and by:.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = phplyr(DataFrame::fromCsv('schools.csv'))->groupBy('school')->get();

// The two best students in each of the first three schools.
echo phplyr($schools)
    ->sliceMax('score', n: 2)
    ->filter(fn ($r) => $r->school <= 'school-03')
    ->select('school', 'score');
$schools = DataFrame::fromCsv('schools.csv') |> group_by('school');

// The two best students in each of the first three schools.
echo $schools
    |> slice_max('score', n: 2)
    |> filter(fn ($r) => $r->school <= 'school-03')
    |> select('school', 'score');

Columns

select() keeps columns by name or with tidyselect helpers. An associative array renames while selecting. rename() renames with new: 'old' arguments, rename_with() applies a function to selected names, and relocate() moves columns to the front or before / after another column.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = DataFrame::fromCsv('schools.csv');

echo implode(', ', (phplyr($schools)->select('school', ends_with('score'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(except('school'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(where('numeric'))->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->select(['hours' => 'study_hours'], everything())->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->relocate('score', before: 'study_hours')->get())->columns()), "\n";
echo implode(', ', (phplyr($schools)->renameWith(strtoupper(...), contains('score'))->get())->columns()), "\n";
$schools = DataFrame::fromCsv('schools.csv');

echo implode(', ', ($schools |> select('school', ends_with('score')))->columns()), "\n";
echo implode(', ', ($schools |> select(except('school')))->columns()), "\n";
echo implode(', ', ($schools |> select(where('numeric')))->columns()), "\n";
echo implode(', ', ($schools |> select(['hours' => 'study_hours'], everything()))->columns()), "\n";
echo implode(', ', ($schools |> relocate('score', before: 'study_hours'))->columns()), "\n";
echo implode(', ', ($schools |> rename_with(strtoupper(...), contains('score')))->columns()), "\n";

mutate() adds or replaces columns. A value can be a row closure, a vector helper, a list with one value per row, a scalar, or null to drop the column. Later arguments see the columns made by earlier ones.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
echo phplyr(DataFrame::fromCsv('housing.csv'))
    ->mutate(
        rent_per_m2: fn ($r) => round($r->monthly_rent / $r->area_m2, 2),
        size: if_else(fn ($r) => $r->area_m2 >= 60, 'large', 'small'),
        rank: min_rank(desc('monthly_rent')),
    )
    ->arrange('rank');
echo DataFrame::fromCsv('housing.csv')
    |> mutate(
        rent_per_m2: fn ($r) => round($r->monthly_rent / $r->area_m2, 2),
        size: if_else(fn ($r) => $r->area_m2 >= 60, 'large', 'small'),
        rank: min_rank(desc('monthly_rent')),
    )
    |> arrange('rank');

mutate() takes dplyr’s options: by groups for one call, keep: 'none' keeps only the grouping and new columns, and before or after place the new columns. transmute() is mutate() that keeps only the new columns.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$housing = DataFrame::fromCsv('housing.csv');

// keep: 'none' keeps only new columns (and grouping columns).
echo phplyr($housing)->mutate(rent_k: fn ($r) => $r->monthly_rent / 1000, keep: 'none')->head(3);

// by groups for this call only; mean() is recycled within each group.
echo "\n", phplyr($housing)
    ->mutate(vs_bedroom_avg: fn ($r, $g) => $r->monthly_rent - mean('monthly_rent')($g), by: 'bedrooms', after: 'bedrooms')
    ->head(4);
$housing = DataFrame::fromCsv('housing.csv');

// keep: 'none' keeps only new columns (and grouping columns).
echo $housing |> mutate(rent_k: fn ($r) => $r->monthly_rent / 1000, keep: 'none') |> head(3);

// by groups for this call only; mean() is recycled within each group.
echo "\n", $housing
    |> mutate(vs_bedroom_avg: fn ($r, $g) => $r->monthly_rent - mean('monthly_rent')($g), by: 'bedrooms', after: 'bedrooms')

pull() returns one column as a PHP list. It takes a name or a position (1-based, negative from the end, the last column by default) and an optional name: column whose values become the keys.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$housing = DataFrame::fromCsv('housing.csv');

echo phplyr($housing)->distinct('bedrooms')->arrange('bedrooms');
echo "\n", json_encode(phplyr($housing)->arrange('area_m2')->pull('monthly_rent')), "\n";
echo json_encode(phplyr($housing)->pull(-1)), "\n";
$housing = DataFrame::fromCsv('housing.csv');

echo $housing |> distinct('bedrooms') |> arrange('bedrooms');
echo "\n", json_encode($housing |> arrange('area_m2') |> pull('monthly_rent')), "\n";
echo json_encode($housing |> pull(-1)), "\n";

Summaries

summarise() returns one row per group. Each named argument is a summary helper or a closure that receives the group’s table and returns one value. With several grouping columns, the result drops the last one, as in dplyr. groups accepts 'drop_last', 'drop', 'keep', and 'rowwise'.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->summarise(
        students: n(),
        schools: n_distinct('school'),
        median_hours: median('study_hours'),
        q90_score: quantile('score', 0.9),
        iqr_score: iqr('score'),
        top_school: fn ($g) => (phplyr($g)->sliceMax('score', n: 1)->pull('school'))[0],
    );
echo DataFrame::fromCsv('schools.csv')
    |> summarise(
        students: n(),
        schools: n_distinct('school'),
        median_hours: median('study_hours'),
        q90_score: quantile('score', 0.9),
        iqr_score: iqr('score'),
        top_school: fn ($g) => ($g |> slice_max('score', n: 1) |> pull('school'))[0],
    );
# A tibble: 1 × 6
  students schools median_hours q90_score iqr_score top_school
     <int>   <int>        <dbl>     <dbl>     <dbl> <chr>     
1      250      12         6.66      86.1      15.3 school-06

reframe() is summarise() for summaries that return several values. Results are recycled to a common length within each group, and the output is ungrouped.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
echo phplyr(DataFrame::fromCsv('schools.csv'))
    ->filter(fn ($r) => $r->school <= 'school-02')
    ->groupBy('school')
    ->reframe(
        p: [0.25, 0.5, 0.75],
        score: fn ($g) => array_map(fn ($p) => Stats::quantile($g->column('score'), $p), [0.25, 0.5, 0.75]),
    );
echo DataFrame::fromCsv('schools.csv')
    |> filter(fn ($r) => $r->school <= 'school-02')
    |> group_by('school')
    |> reframe(
        p: [0.25, 0.5, 0.75],
        score: fn ($g) => array_map(fn ($p) => Stats::quantile($g->column('score'), $p), [0.25, 0.5, 0.75]),
    );

count() counts rows per combination of columns within any existing groups and keeps the original grouping. wt: sums a column instead, sort: true orders by the count, and name: names the count column. tally() counts within the current groups, and add_count() and add_tally() add the count as a column.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = phplyr(DataFrame::fromCsv('schools.csv'))
    ->mutate(band: case_when(
        [fn ($r) => $r->study_hours < 4, 'light'],
        [fn ($r) => $r->study_hours < 8, 'moderate'],
        default: 'heavy',
    ))
    ->get();

echo phplyr($schools)->count('band', sort: true);
echo "\n", phplyr($schools)->count('band', wt: 'study_hours', name: 'hours');
$schools = DataFrame::fromCsv('schools.csv')
    |> mutate(band: case_when(
        [fn ($r) => $r->study_hours < 4, 'light'],
        [fn ($r) => $r->study_hours < 8, 'moderate'],
        default: 'heavy',

echo $schools |> count('band', sort: true);
echo "\n", $schools |> count('band', wt: 'study_hours', name: 'hours');
