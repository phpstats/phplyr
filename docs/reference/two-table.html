Joins, binding, and set operations

Joins

The join functions take the right-hand table as their first argument. The input table is the left-hand table x.

Function Rows kept
inner_join($y) Rows of x with a match in y
left_join($y) All rows of x
right_join($y) All rows of y
full_join($y) All rows of both
semi_join($y) Rows of x with a match, x’s columns only
anti_join($y) Rows of x without a match
cross_join($y) Every combination

by: names the key columns. A string or list joins on columns with the same name in both tables, and an associative array maps differing names: by: ['school' => 'school_id']. The forms mix, as in ['id', 'code' => 'country_code']. Without by:, the tables join on every column they share.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$schools = phplyr(DataFrame::fromCsv('schools.csv'))
    ->group_by('school')
    ->summarise(avg_score: mean('score'))
    ->get();

$districts = DataFrame::fromRows([
    ['school_id' => 'school-01', 'district' => 'North'],
    ['school_id' => 'school-02', 'district' => 'North'],
    ['school_id' => 'school-03', 'district' => 'South'],
    ['school_id' => 'school-99', 'district' => 'East'],
]);

echo phplyr($schools)->inner_join($districts, by: ['school' => 'school_id']);
echo "\n", phplyr($schools)->left_join($districts, by: ['school' => 'school_id'])->head(5);
echo "\n", phplyr($districts)->anti_join($schools, by: ['school_id' => 'school']);

The options follow dplyr 1.1:

  • suffix: renames clashing non-key columns, ['.x', '.y'] by default.
  • keep: true keeps y’s key columns.
  • na_matches: 'never' stops NA keys from matching. By default NA matches NA.
  • multiple: is 'all', 'any', 'first', or 'last'.
  • unmatched: 'error' throws when rows would be dropped.
  • relationship: checks 'one-to-one', 'one-to-many', 'many-to-one', or 'many-to-many'. An unexpected many-to-many join raises dplyr’s warning.
  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$x = DataFrame::fromRows([['id' => 1, 'v' => 'a'], ['id' => 2, 'v' => 'b'], ['id' => null, 'v' => 'c']]);
$y = DataFrame::fromRows([['id' => 2, 'v' => 'B'], ['id' => 2, 'v' => 'B2'], ['id' => null, 'v' => 'C']]);

// Clashing columns get suffixes; NA keys match each other, as in dplyr.
echo phplyr($x)->left_join($y, by: 'id');

// Keep only the first match, and never match NA keys.
echo "\n", phplyr($x)->left_join($y, by: 'id', multiple: 'first', na_matches: 'never', suffix: ['_x', '_y']);
$x = DataFrame::fromRows([['id' => 1, 'v' => 'a'], ['id' => 2, 'v' => 'b'], ['id' => null, 'v' => 'c']]);

echo $x |> left_join($y, by: 'id');

// Keep only the first match, and never match NA keys.
echo "\n", $x |> left_join($y, by: 'id', multiple: 'first', na_matches: 'never', suffix: ['_x', '_y']);

Joins keep x’s grouping, except for a grouping column that the join renames.

join_by()

join_by() builds dplyr’s join specifications. A string is an equality on the same column name, ['a' => 'b'] maps names, and a comparison of two col() expressions compares x’s column (left) with y’s (right). Every condition must hold.

join_by('id', col('t')->ge(col('start')), col('t')->lt(col('end')))
join_by('id', between('t', 'start', 'end'))        // start and end are y's columns
join_by('id', closest(col('t')->ge(col('start'))))  // the latest start at or before t
join_by(within('lo', 'hi', 'start', 'end'))         // x's interval inside y's
join_by(overlaps('lo', 'hi', 'start', 'end'))

For inequality, rolling, and overlap joins, keep defaults to dplyr’s behavior: equality keys are merged and the columns in other conditions are kept from both tables. keep: false is an error for these joins. Database tables run them in SQL, except right and full rolling joins, which load the rows.

nest_join() keeps every row of x and adds a list-column (name:, default 'data') holding each row’s matching rows of y as a table.

Binding

bind_rows() stacks tables under the input one, matching columns by name and filling missing columns with NA. _id: adds a column with each row’s source. bind_cols() puts tables side by side and renames duplicate names as name...position.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$a = DataFrame::fromRows([['id' => 1, 'v' => 'a']]);
$b = DataFrame::fromRows([['id' => 2, 'w' => true]]);

echo phplyr($a)->bind_rows($b, _id: 'source');
echo "\n", phplyr($a)->bind_cols(DataFrame::fromRows([['id' => 10]]));
$a = DataFrame::fromRows([['id' => 1, 'v' => 'a']]);
$b = DataFrame::fromRows([['id' => 2, 'w' => true]]);

echo $a |> bind_rows($b, _id: 'source');
echo "\n", $a |> bind_cols(DataFrame::fromRows([['id' => 10]]));
# A tibble: 2 × 4
  source    id v     w    
  <chr>  <int> <chr> <lgl>
1 1          1 a     NA   
2 2          2 <NA>  TRUE 
# A tibble: 1 × 3
  id...1 v     id...3
   <int> <chr>  <int>
1      1 a         10

Set operations and row updates

union(), union_all(), intersect(), setdiff(), and symdiff() compare whole rows. setequal() returns true when both tables hold the same distinct rows.

The rows_*() functions modify the input table using another table’s rows, matched on by: (y’s first column by default):

  • rows_insert() adds rows with new keys; conflict: 'ignore' skips existing keys.
  • rows_append() adds all rows.
  • rows_update() overwrites values for matching keys.
  • rows_patch() fills only NA values for matching keys.
  • rows_upsert() updates matching keys and inserts new ones.
  • rows_delete() removes matching keys.

unmatched: 'ignore' allows y keys that x lacks.

  • Method chain (PHP 8.3+)
  • Pipe (PHP 8.5)
$stock = DataFrame::fromRows([
    ['sku' => 'A1', 'qty' => 5],
    ['sku' => 'B2', 'qty' => null],
    ['sku' => 'C3', 'qty' => 0],
]);
$delivery = DataFrame::fromRows([['sku' => 'B2', 'qty' => 12], ['sku' => 'D4', 'qty' => 3]]);

echo phplyr($stock)->rows_upsert($delivery, by: 'sku');
echo "\n", phplyr($stock)->rows_patch($delivery, by: 'sku', unmatched: 'ignore');
echo "\n", phplyr($stock)->setdiff(DataFrame::fromRows([['sku' => 'C3', 'qty' => 0]]));
