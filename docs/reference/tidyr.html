tidyr

The tidyr functions use tidyr’s argument names in camelCase, and tidyr’s dot-arguments take a leading underscore. See Underscored arguments.

Pivoting

pivot_longer(cols) turns the selected columns into rows of names and values.

Option Default Effect
namesTo 'name' Column, or columns, for the names. '.value' takes a value column’s name from that part.
valuesTo 'value' Column for the values
namesPrefix none Regular expression removed from the start of each name
namesSep, namesPattern none Split names into several namesTo columns, by separator or by regex groups
valuesDropNa false Drop rows whose values are all NA
namesTransform, valuesTransform none A closure, or an array of closures by column
colsVary 'fastest' 'slowest' keeps each source column’s rows together

pivot_wider() spreads names and values into columns.

Option Default Effect
namesFrom, valuesFrom 'name', 'value' Columns that supply the new names and their values
idCols every other column Columns that identify the output rows
valuesFill NA Value for missing cells
valuesFn none Combines duplicate cells
namesPrefix, namesSep, namesGlue, namesSort '', '_', none, false Control the new names
namesVary 'fastest' 'slowest' groups each name’s value columns together
namesExpand, idExpand false Add every combination of the namesFrom or idCols values, sorted, factors by level
unusedFn none Summarizes columns in none of idCols, namesFrom, and valuesFrom

Without valuesFn, duplicate cells turn the value columns into list-columns and trigger a PHP warning with tidyr’s message.

build_longer_spec() and build_wider_spec() return tidyr’s pivot spec as a table, and pivot_longer_spec() and pivot_wider_spec() run an edited one. The superseded gather() and spread() are also available.

  • PHP 8.5+
  • PHP 8.3–8.4
$scores = DataFrame::fromRows([
    ['student' => 'ann', 'wk1' => 10, 'wk2' => null, 'wk3' => 30],
    ['student' => 'bob', 'wk1' => 7, 'wk2' => 8, 'wk3' => 9],
]);

$long = $scores |> pivot_longer(starts_with('wk'), namesTo: 'week', namesPrefix: 'wk', valuesTo: 'points', valuesDropNa: true);
echo $long;

echo "\n", $long |> pivot_wider(namesFrom: 'week', valuesFrom: 'points', namesPrefix: 'week_', valuesFill: 0, namesSort: true);
$scores = DataFrame::fromRows([
    ['student' => 'ann', 'wk1' => 10, 'wk2' => null, 'wk3' => 30],
    ['student' => 'bob', 'wk1' => 7, 'wk2' => 8, 'wk3' => 9],
]);

$long = phplyr($scores)->pivotLonger(starts_with('wk'), namesTo: 'week', namesPrefix: 'wk', valuesTo: 'points', valuesDropNa: true)->get();
echo $long;

echo "\n", phplyr($long)->pivotWider(namesFrom: 'week', valuesFrom: 'points', namesPrefix: 'week_', valuesFill: 0, namesSort: true);
# A tibble: 5 × 3
  student week  points
  <chr>   <chr>  <int>
1 ann     1         10
2 ann     3         30
3 bob     1          7
4 bob     2          8
5 bob     3          9
# A tibble: 2 × 4
  student week_1 week_2 week_3
  <chr>    <int>  <int>  <int>
1 ann         10      0     30
2 bob          7      8      9

pivot_longer()

pivot_longer(mixed $cols, array|string $namesTo = 'name', string $valuesTo = 'value', ?string $namesPrefix = null, ?string $namesSep = null, ?string $namesPattern = null, bool $valuesDropNa = false, Closure|array|null $namesTransform = null, Closure|array|null $valuesTransform = null, string $colsVary = 'fastest'): Closure

Lengthen: turn columns into name/value rows. pivot_longer(starts_with('wk'), namesTo: 'week', valuesTo: 'rank'). namesTo may list several names (with namesSep or namesPattern); the name ‘.value’ takes the value column’s name from that part. namesTransform and valuesTransform are a closure, or name => closure; colsVary: ‘slowest’ keeps each source column’s rows together.

Returns a function of a table, which returns a table. Chain method: ->pivotLonger(). Example.

pivot_wider()

pivot_wider(mixed $namesFrom = 'name', mixed $valuesFrom = 'value', mixed $idCols = null, string $namesPrefix = '', string $namesSep = '_', ?string $namesGlue = null, bool $namesSort = false, mixed $valuesFill = null, Closure|array|null $valuesFn = null, string $namesVary = 'fastest', bool $namesExpand = false, bool $idExpand = false, Closure|array|null $unusedFn = null): Closure

Widen: spread name/value pairs into columns. pivot_wider(namesFrom: 'week', valuesFrom: 'rank', valuesFill: 0). Duplicate cells need valuesFn, a closure taking the list of values. namesVary: ‘slowest’ groups each name’s value columns together; namesExpand and idExpand add every combination of the namesFrom and idCols values (sorted, factors by level); unusedFn summarises the columns that are in none of idCols, namesFrom, and valuesFrom.

Returns a function of a table, which returns a table. Chain method: ->pivotWider(). Example.

Missing combinations and values

complete() adds missing combinations of the given columns and fills other columns with NA, or with values from fill:. A column name expands to its unique values (a factor to its levels), nesting() keeps only combinations that occur, and a named list supplies the values. It works within groups. expand() returns only the combinations, and crossing() and expand_grid() build a new table from lists.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromRows([
    ['shop' => 'north', 'month' => 1, 'sales' => 10],
    ['shop' => 'north', 'month' => 3, 'sales' => 12],
    ['shop' => 'south', 'month' => 2, 'sales' => 7],
]) |>
    complete('shop', month: [1, 2, 3], fill: ['sales' => 0]);
echo phplyr(DataFrame::fromRows([
    ['shop' => 'north', 'month' => 1, 'sales' => 10],
    ['shop' => 'north', 'month' => 3, 'sales' => 12],
    ['shop' => 'south', 'month' => 2, 'sales' => 7],
]))
    ->complete('shop', month: [1, 2, 3], fill: ['sales' => 0]);
# A tibble: 6 × 3
  shop  month sales
  <chr> <int> <int>
1 north     1    10
2 north     2     0
3 north     3    12
4 south     1     0
5 south     2     7
6 south     3     0

fill() carries values down or up over NA within groups (_direction: 'down' | 'up' | 'downup' | 'updown'). drop_na() drops rows with NA in the given columns, and replace_na() replaces NA per column.

  • PHP 8.5+
  • PHP 8.3–8.4
echo DataFrame::fromRows([
    ['quarter' => 'Q1', 'year' => 2024, 'sales' => 10],
    ['quarter' => 'Q2', 'year' => null, 'sales' => null],
    ['quarter' => 'Q3', 'year' => null, 'sales' => 14],
]) |>
    fill('year') |>
    replace_na(['sales' => 0]);
echo phplyr(DataFrame::fromRows([
    ['quarter' => 'Q1', 'year' => 2024, 'sales' => 10],
    ['quarter' => 'Q2', 'year' => null, 'sales' => null],
    ['quarter' => 'Q3', 'year' => null, 'sales' => 14],
]))
    ->fill('year')
    ->replaceNa(['sales' => 0]);
# A tibble: 3 × 3
  quarter  year sales
  <chr>   <int> <int>
1 Q1       2024    10
2 Q2       2024     0
3 Q3       2024    14

complete()

complete(mixed ...$items): Closure

Add missing combinations, filling other columns with NA (or with fill). complete('year', 'type', fill: ['n' => 0]). Option: explicit (default true; false fills only the added rows).

Returns a function of a table, which returns a table. Chain method: ->complete(). Example.

expand()

expand(mixed ...$items): Closure

Every combination of the given columns, per group: expand('year', 'type'), expand(nesting('id', 'name'), 'year'), expand(year: range(2000, 2005)).

Returns a function of a table, which returns a table. Chain method: ->expand().

nesting()

nesting(mixed ...$columns): Nesting

Only the combinations that occur in the data, for complete() and expand().

Returns Nesting.

crossing()

crossing(array ...$columns): Phibble\DataFrame

Every combination of unique values (sorted), as a new table: crossing(x: [1, 2], y: ['a', 'b']).

Returns Phibble\DataFrame.

expand_grid()

expand_grid(array ...$columns): Phibble\DataFrame

Every combination of the values as given, first column varying slowest.

Returns Phibble\DataFrame.

full_seq()

full_seq(array $x, int|float $period, float $tol = 1.0E-6): array

Every value from the smallest to the largest of x in steps of period: full_seq([1, 5, 3], 1) is [1, 2, 3, 4, 5]. Values off the grid (beyond tol) are an error.

Returns array. Throws InvalidArgumentException on invalid arguments.

fill()

fill(mixed ...$cols): Closure

Fill NA with the previous (or next) value, within groups: fill('price', _direction: 'down'|'up'|'downup'|'updown').

Returns a function of a table, which returns a table. Chain method: ->fill(). Throws InvalidArgumentException on invalid arguments. An unknown underscored option throws InvalidArgumentException. Example.

drop_na()

drop_na(mixed ...$cols): Closure

Drop rows with NA in any of the columns (any column when none are given).

Returns a function of a table, which returns a table. Chain method: ->dropNa().

replace_na()

replace_na(array $replace): Closure

Replace NA per column: replace_na(['n' => 0, 'label' => 'unknown']).

Returns a function of a table, which returns a table. Chain method: ->replaceNa(). Example.

uncount()

uncount(mixed $weights, bool $_remove = true, ?string $_id = null): Closure

Repeat each row by a weight column: uncount('n'). Options: _remove (drop the weight column, default true), _id (add a 1-based copy number).

Returns a function of a table, which returns a table. Chain method: ->uncount(). Throws InvalidArgumentException on invalid arguments.

tooFew and tooMany handle pieces that don’t fit, as in tidyr.

  • PHP 8.5+
  • PHP 8.3–8.4
$t = DataFrame::fromRows([
    ['id' => 1, 'name' => 'Ada Lovelace', 'tags' => 'math,code'],
    ['id' => 2, 'name' => 'Grace Hopper', 'tags' => 'navy'],
]);

echo $t |> separate_wider_delim('name', ' ', names: ['first', 'last']);
echo "\n", $t |> select('id', 'tags') |> separate_longer_delim('tags', ',');
echo "\n", $t |> select('id', 'name') |> unite('label', 'id', 'name', sep: ': ');

separate_wider_delim()

separate_wider_delim(mixed $cols, string $delim, ?array $names = null, ?string $namesSep = null, string $tooFew = 'error', string $tooMany = 'error', bool $colsRemove = true): Closure

Split columns on a fixed delimiter into new columns: separate_wider_delim('name', ' ', names: ['first', 'last']). Without names, give namesSep to name them col{sep}1, col{sep}2… tooFew: ‘error’|‘align_start’|‘align_end’; tooMany: ‘error’|‘drop’|‘merge’.

Returns a function of a table, which returns a table. Chain method: ->separateWiderDelim(). Throws InvalidArgumentException, UnexpectedValueException on invalid arguments. Example.

separate_wider_position()

separate_wider_position(mixed $cols, array $widths, string $tooFew = 'error', bool $colsRemove = true): Closure

Split columns by character widths: separate_wider_position('code', ['state' => 2, 1, 'county' => 3]); unnamed widths are skipped.

Returns a function of a table, which returns a table. Chain method: ->separateWiderPosition(). Throws UnexpectedValueException on invalid arguments.

separate_wider_regex()

separate_wider_regex(mixed $cols, array $patterns, string $tooFew = 'error', bool $colsRemove = true): Closure

Split columns with regular expressions: separate_wider_regex('id', ['letters' => '[a-z]+', '-', 'digits' => '\d+']). Unnamed patterns match but are not kept. Rows that don’t match error unless tooFew: ‘align_start’.

Returns a function of a table, which returns a table. Chain method: ->separateWiderRegex(). Throws UnexpectedValueException on invalid arguments.

separate_longer_delim()

separate_longer_delim(mixed $cols, string $delim): Closure

Split columns on a fixed delimiter into rows: separate_longer_delim('tags', ','). Several columns must split into the same number of pieces (or one).

Returns a function of a table, which returns a table. Chain method: ->separateLongerDelim(). Example.

separate_longer_position()

separate_longer_position(mixed $cols, int $width): Closure

Split columns into rows of $width characters.

Returns a function of a table, which returns a table. Chain method: ->separateLongerPosition().

separate()

separate(string $col, array $into, array|string|int $sep = '[^[:alnum:]]+', bool $remove = true, bool $convert = false, string $extra = 'warn', string $fill = 'warn'): Closure

Split a string column into several (superseded in tidyr, still common): separate('date', ['year', 'month'], sep: '-'). sep is a regular expression, or an int / list of ints for positions. extra: ‘warn’|‘drop’|‘merge’; fill: ‘warn’|‘right’|‘left’; convert: R’s type.convert().

Returns a function of a table, which returns a table. Chain method: ->separate().

separate_rows()

separate_rows(mixed ...$cols): Closure

Split columns on a regular expression into rows (superseded by separate_longer_delim()): separate_rows('tags', sep: ','). Options: sep (default ‘[1.]+’), convert.

Returns a function of a table, which returns a table. Chain method: ->separateRows().

extract()

extract(string $col, array $into, string $regex = '([[:alnum:]]+)', bool $remove = true, bool $convert = false): Closure

Pull regular-expression groups into new columns (superseded by separate_wider_regex()): extract('x', ['letter', 'digit'], '([a-z])(\d)'). A null name skips a group. Rows that don’t match get NA.

Returns a function of a table, which returns a table. Chain method: ->extract().

unite()

unite(string $col, mixed ...$cols): Closure

Paste columns together into one: unite('date', 'year', 'month', sep: '-'). Options: sep (’_’), remove (true), naRm (false; NA otherwise prints “NA”).

Returns a function of a table, which returns a table. Chain method: ->unite(). Example.

List-columns

A list element is a PHP array. A list is R’s unnamed list or vector, and an array with string keys is a named list.

Function Use
unnest_wider(col, namesSep:) One column per name; unnamed elements need namesSep
unnest_longer(col, valuesTo:, indicesTo:, indicesInclude:, keepEmpty:) One row per element, with names or positions in {col}_id
hoist(col, name: path, _remove:) Pull components out by name, 1-based position, or a list path
chop(cols), unchop(cols, keepEmpty:) Collapse rows into list-columns and back
pack(name: cols, _namesSep:), unpack(cols, namesSep:) Columns into a column of named arrays and back

chop, pack, unpack, and extract share names with PHP built-ins, so import them with use function Phplyr\{chop, pack, unpack, extract};.

  • PHP 8.5+
  • PHP 8.3–8.4
use function Phplyr\chop;

$people = DataFrame::fromColumns([
    'id' => [1, 2, 3],
    'info' => [
        ['name' => 'ann', 'langs' => ['php', 'r'], 'city' => ['name' => 'Oslo']],
        ['name' => 'bob', 'langs' => ['sql']],
        null,
    ],
]);

echo $people |> hoist('info', town: ['city', 'name']), "\n";

echo $people |> unnest_wider('info') |> select('id', 'langs') |> unnest_longer('langs', indicesInclude: true), "\n";

echo DataFrame::fromColumns(['g' => ['a', 'a', 'b'], 'x' => [1, 2, 3]]) |> chop('x');

nest()

nest(mixed ...$spec): Closure

Nest columns into a list-column of tables: nest(data: ['x', 'y']), or nest() on a grouped table to nest everything but the groups.

Returns a function of a table, which returns a table. Chain method: ->nest(). Throws InvalidArgumentException on invalid arguments.

unnest()

unnest(array|string $cols, bool $keepEmpty = false): Closure

Unnest list-columns of tables back into rows.

Returns a function of a table, which returns a table. Chain method: ->unnest().

unnest_longer()

unnest_longer(mixed $col, ?string $valuesTo = null, ?string $indicesTo = null, ?bool $indicesInclude = null, bool $keepEmpty = false): Closure

Turn each element of list-columns into rows: unnest_longer('tags'). Elements with names add an index column of the names ({col}_id); with indicesInclude: true, unnamed elements add 1-based positions. Empty and NA elements drop their row unless keepEmpty: true. valuesTo and indicesTo may use {col}. Several columns must have elements of the same length in each row, or length one.

Returns a function of a table, which returns a table. Chain method: ->unnestLonger(). Example.

unnest_wider()

unnest_wider(mixed $col, ?string $namesSep = null): Closure

Turn each element of list-columns into columns: unnest_wider('meta'). Named elements give a column per name, in order of first appearance; unnamed elements need namesSep, which names them {col}{sep}1, {col}{sep}2… (namesSep also prefixes named ones). Missing names and NA elements become NA.

Returns a function of a table, which returns a table. Chain method: ->unnestWider(). Example.

hoist()

hoist(string $col, mixed ...$paths): Closure

Pull components out of a list-column into new columns, before it: hoist('meta', name: 'name', first: 1, city: ['address', 'city']). A path is a name, a 1-based position, or a list of them for nested elements. With _remove (the default), hoisted components are removed from the list-column, and the column is dropped once every element is empty.

Returns a function of a table, which returns a table. Chain method: ->hoist(). An unknown underscored option throws InvalidArgumentException. Example.

chop()

chop(mixed $cols): Closure

Collapse rows into list-columns: chop(['x', 'y']) gives one row per combination of the other columns (in order of first appearance), with x and y as lists.

Returns a function of a table, which returns a table. Chain method: ->chop(). Example.

unchop()

unchop(mixed $cols, bool $keepEmpty = false): Closure

Expand list-columns into rows, the reverse of chop(). Empty and NA elements drop their row unless keepEmpty: true.

Returns a function of a table, which returns a table. Chain method: ->unchop().

pack()

pack(mixed ...$spec): Closure

Pack columns into a column of named arrays (tidyr’s data frame columns): pack(dims: ['width', 'height']). Packed columns go at the end. With _namesSep, the inner names drop their outer name and the separator.

Returns a function of a table, which returns a table. Chain method: ->pack(). An unknown underscored option throws InvalidArgumentException.

unpack()

unpack(mixed $cols, ?string $namesSep = null): Closure

Spread columns of named arrays into columns, the reverse of pack().

Returns a function of a table, which returns a table. Chain method: ->unpack().
